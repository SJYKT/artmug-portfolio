# ARTmug Portfolio V12 — Clean

이번 버전은 과한 포스터/브러시/글래스 텍스트 효과를 전부 제거한 정리 버전입니다.

- `지금, 저점매수하세요.` 텍스트: 완전 정적
- 포트폴리오 4개: 한 줄 4열 / 모바일 2×2
- 카드에만 아주 약한 3D tilt
- 터치 기기에서는 tilt 자동 비활성화
- BEST / GOOD / OK를 초록 / 골드 / 회색으로 구분
- 영상 팝업은 클릭한 카드 위치 근처에 표시
- 아트머그 캐시 회피용 새 파일명 `artmug-v12-clean.html` 사용

GitHub 저장소 최상단에 아래 파일을 업로드하세요.

- index.html
